# GTS Container — Website

Website for GTS Container: PUF office cabins, site offices, security cabins and labour accommodation in Chennai, Bengaluru and Mysore.

## Files
- `index.html` — the entire site (HTML, CSS and JS in one file)

## Run locally
Open `index.html` in any browser.

## Publish with GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/`.

To use your own domain (gtscontainerservice.in), add it under **Settings → Pages → Custom domain** and point your DNS to GitHub Pages.

## Editing
- WhatsApp number: `const WHATSAPP` near the bottom of `index.html`
- Phone, email and addresses: search for them in `index.html`
